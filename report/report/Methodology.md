## Data Source

The analysis was conducted using recruitment and outreach data provided by Local Educational Nonprofit (LEN). The dataset included recruitment channels, outreach events, scholar matches, follow-up activity, and basic cost information for selected recruitment initiatives. Organization-specific details have been anonymized.

## Analytical Approach

The analysis focused on answering four key business questions:

1. Which recruitment channels generated the strongest outcomes?
2. Which outreach strategies produced the highest conversion rates?
3. Which recruitment efforts were the most cost-effective?
4. Where should future recruitment efforts be concentrated to support organizational growth?

## Key Metrics

The analysis evaluated recruitment performance using several key metrics, including:

- Recruitment channel conversion rates
- Cost per successful scholar match
- Scholar retention by recruitment source
- Recruitment funnel analysis
- Geographic distribution of outreach and scholar matches

## Project Limitations

- The analysis was based on the data provided by LEN at the time of the project.
- Some recruitment activities and outcomes may not have been captured in the available dataset.
- Recommendations were developed using the available quantitative data and should be considered alongside organizational priorities and future data collection efforts.
